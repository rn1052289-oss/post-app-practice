# カフェアプリ 画面一覧

| ID    | 画面名       | 役割                                                                         | 主な利用者 |
| :---- | :----------- | :--------------------------------------------------------------------------- | :--------- |
| SC-01 | メニュー画面 | その日のドリンンクとフードを一覧でみせ、商品と個数を選ぶ（最初に見せる画面） | お客様     |
| SC-02 | カート画面   | 選んだ商品と個数、合計金額を確かめる                                         | お客様     |
| SC-03 | 支払いの画面 | 外部決済サービスに支払いを依頼し、その結果を受け取る                         | お客様     |
| SC-04 | 注文完了画面 | 注文を受けたことと、注文番号を 知らせる                                      | お客様     |
| SC-05 | 注文状況画面 | 注文番号で、注文がお店に届いているかを確かめ、取り消す                       | お客様     |
| SC-06 | 注文一覧画面 | 受け取り前の注文を、注文番号とともに一覧で見る（最初に開く画面）             | 店員       |
| SC-07 | 注文詳細画面 | 選んだ注文の商品と個数を見て、受け渡し済みにする                             | 店員       |
