# 投稿編集画面 画面項目定義

| 項目名 | 種類 | 必須 | 内容 |
| --- | --- | --- | --- |
| 投稿編集 | 見出し | - | 投稿を編集する画面であることを示す |
| タイトル | テキスト入力 | 必須 | 投稿のタイトルを入力する |
| カテゴリ | セレクトボックス | 必須 | 「お知らせ」「技術メモ」「雑記」からカテゴリを選択する |
| 本文 | テキストエリア | 必須 | 投稿の本文を入力する |
| 更新 | ボタン | - | 入力した内容で投稿を更新する |
| キャンセル | リンク | - | 投稿を更新せず、投稿一覧画面へ戻る |
