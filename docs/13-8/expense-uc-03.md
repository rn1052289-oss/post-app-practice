# 経費精算アプリ ユースケース記述

#### UC-03: 申請を承認する

- **対応機能**: F-03 申請内容の確認と承認
- **アクター**: 承認者
- **事前条件**: 自分あての申請中の申請が1件以上ある
- **基本フロー**:
    1. 承認者が SC-04 承認待ち一覧画面を開く
    2. システムが自分あての申請中の申請を一覧表示する
    3. 承認者が申請を1件選ぶ
    4. システムが SC-05 申請詳細画面に使った日・金額・費目・用途を表示する
    5. 承認者が「承認する」を押す
    6. システムが承認済みとして記録し、SC-04 承認待ち一覧画面に戻して、その申請を一覧から外す
- **代替フロー**:
    - 5a. 承認者が差し戻しの理由を書いて「差し戻す」を押した場合：システムは理由とともに差し戻しとして記録し、SC-04 承認待ち一覧画面に戻して、その申請を一覧から外す（F-04／UC-04 申請を差し戻す）
    - 5b. 承認者が差し戻しの理由が空のまま「差し戻す」を押した場合：システムは理由の入力を求め、状態を変えない
- **事後条件**: 承認した申請は承認済み、差し戻した申請は理由を伴う差し戻しとして記録され、承認待ち一覧から外れる。理由が空のまま差し戻そうとした場合は申請中のまま
- **受け入れ条件**:
    - [ ] 承認待ち一覧画面で申請を選ぶと、その申請の使った日・金額・費目・用途が表示される
    - [ ] 「承認する」を押すと、その申請が承認待ち一覧から消える
    - [ ] 理由を書いて「差し戻す」を押すと、その申請が承認待ち一覧から消え、申請者の申請一覧に理由が表示される
