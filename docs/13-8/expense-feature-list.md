# 経費精算アプリ 機能一覧

## 機能一覧

| ID   | 機能                           | 主な利用者 |
| :--- | :----------------------------- | :--------- |
| F-01 | 経費申請の提出                 | 申請者     |
| F-02 | 申請状況の確認                 | 申請者     |
| F-03 | 申請内容の確認と承認           | 承認者     |
| F-04 | 申請の差し戻し                 | 承認者     |
| F-05 | 差し戻された申請の修正と再提出 | 申請者     |

## 今回作らないもの

| 作らないもの                         | 理由                                                                 |
| :----------------------------------- | :------------------------------------------------------------------- |
| 領収書の写真の添付                   | 「まずは無し」と書かれていて、依頼の時点で対象外と決まっているため   |
| 振込の手続きと会計ソフトへの取り込み | 総務が手で進めると書かれていて、依頼の時点で対象外と決まっているため |

| F-04 申請の差し戻し                 | UC-04 申請を差し戻す             |
