# 会員登録 テストケース

#### TC-01: ログインしていなくてもトップページが開ける

- **区分**: 正常系
- **前提**: ユーザーがログインしていない
- **手順**:
    1. ブラウザを開く
    2. トップページのURLにアクセスする
- **期待する結果**: ログインしていなくても、トップページが正常に表示される
- **元になった設計書**: 画面一覧の `SC-01` の行

#### TC-02: 正しい情報を入力するとユーザー登録ができる

- **区分**: 正常系
- **前提**: 入力するメールアドレスがまだ登録されていない
- **手順**:
    1. 新規登録画面を開く
    2. 名前を入力する
    3. 未登録のメールアドレスを入力する
    4. パスワードと確認用パスワードを正しく入力する
    5. 「登録」を押す
- **期待する結果**: ユーザー登録が成功し、`users` テーブルにユーザーが1件追加される
- **元になった設計書**: `CreateNewUser.php` の入力の決めごと

#### TC-03: 名前が空欄の場合はユーザー登録ができない

- **区分**: 異常系
- **前提**: 入力するメールアドレスがまだ登録されていない
- **手順**:
    1. 新規登録画面を開く
    2. 名前を空欄のままにする
    3. メールアドレスとパスワードを正しく入力する
    4. 「登録」を押す
- **期待する結果**: 登録が受け付けられず、名前が必須であることを示すエラーメッセージが表示される。`users` テーブルにユーザーは追加されない
- **元になった設計書**: `CreateNewUser.php` の `name` の必須

#### TC-04: 名前が255文字の場合はユーザー登録ができる

- **区分**: 境界値
- **前提**: 入力するメールアドレスがまだ登録されていない
- **手順**:
    1. 新規登録画面を開く
    2. 名前に255文字の文字列を入力する
    3. メールアドレスとパスワードを正しく入力する
    4. 「登録」を押す
- **期待する結果**: ユーザー登録が成功し、`users` テーブルにユーザーが1件追加される。入力した255文字の名前が正しく保存される
- **元になった設計書**: `CreateNewUser.php` の `name` の上限

#### TC-06: すでに登録されているメールアドレスでは登録できない

- **区分**: 異常系
- **前提**: そのメールアドレスのユーザーが、すでに1件登録されている
- **手順**:
    1. 新規登録画面を開く
    2. 名前とパスワードを正しく入れる
    3. メールアドレスに、すでに登録されているものを入れて「登録」を押す
- **期待する結果**: 登録が受け付けられず、そのメールアドレスがすでに使われていることが画面に表示される。そのメールアドレスのユーザーは1件のままになる
- **元になった設計書**: `CreateNewUser.php` の `email` の重複禁止
